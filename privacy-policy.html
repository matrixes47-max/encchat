2. How Messages Work

All messages are encrypted on your device before being sent. The server only sees encrypted ciphertext and has no ability to decrypt it.

  • ✅ Messages encrypted with AES-256-GCM + ChaCha20
  • ✅ Room names never reach the server (SHA-256 hash only)
  • ✅ Messages auto-deleted after TTL (10 seconds to 24 hours)
  • ✅ No persistent database — in-memory only
  • ✅ Keys zeroed on tab/app close

3. Technical Data

Rate Limiting (Anonymous)

To prevent abuse, we store a SHA-256 hash of your IP address (not the IP itself) temporarily in memory for rate limiting. This hash cannot be reversed to identify you. It is never written to disk and is cleared automatically.

4. Android App

  • ✅ FLAG_SECURE — Screenshots and screen recording are blocked
  • ✅ No analytics SDK
  • ✅ No crash reporting that sends data
  • ✅ No third-party trackers
  • ✅ Minimum permissions required

5. Third-Party Services

  • Render.com — Hosting provider (may have standard server logs, see their privacy policy)
  • GitHub — Source code hosting

We do not use Google Analytics, Facebook Pixel, or any advertising networks.

6. Data Retention

  • Messages: Deleted after TTL expires (max 24 hours)
  • IP hashes: Cleared automatically from memory
  • Everything else: Not collected, therefore not retained

7. Children's Privacy

encchat does not knowingly collect information from children under 13. If you are under 13, please do not use this service.
